# 自写插件索引

仓库里的自研/本地插件一览。标 **bundle** 的写进了 `package.json` 的 `dsh.profile.bundles`；
标 **file** 的是 `cordis.patch.yml` 里用 `file://` 直接挂载的单文件插件。

## 生效中的

| 目录 | 包名 | 挂载方式 | 作用 |
|---|---|---|---|
| `EAC-skin-loader/` | `@dsh-eac/skin-loader-pack` | bundle（`link:`） | 皮肤加载器，多个皮肤包在 `packages/skins/` 下 |
| `dsh-our-free-model/` | `dsh-our-free-model` | bundle（`link:`） | 自建模型目录与适配器，设置面板里有入口 |
| `workbuddy-to-dsh/dsh-plugin/` | `dsh-plugin-workbuddy` | bundle（`link:`） | WorkBuddy 本机中转插件 |
| `whale-widget/` | `dsh-whale-widget` | bundle（`link:`） | Web 界面右下角余额小鲸鱼挂件 |
| `gpt-quota-plugin/` | `dsh-gpt-quota` | **file** | GPT 配额浮窗（宿主半 + 浏览器覆盖层） |
| `gpt-bridge-autostart/` | `dsh-gpt-bridge-autostart` | **file** | 用 DSH subprocess 服务拉起 codex 桥，DSH 退出时终止子进程 |

## 加新插件时的固定套路

1. 源码放仓库根下独立目录（不要塞进别的插件里）
2. 需要 `link:` 的，改 `config/profiles/desktop/package.json` 的 `dependencies` + `dsh.profile.bundles`
3. 只是单文件挂载的，改 `config/profiles/desktop/cordis.patch.yml` 的 `- insert:`
4. **路径一律写占位符**：`@DSH_COMPONENTS@/你的目录`，不要写 `D:/AA12583/...`
5. 跑一遍 `.\scripts\capture-profile.ps1` 确认模板能对上，再 push

> 别用 `- insert:` 去挂一个 bundle 里已经有的 id（比如 `image-gen`、`desktop-pet`）——
> Loader 会在同一个 id 下留两条记录，谁生效取决于层顺序。改它们要用 `- id:` 覆盖。
